# Tic Tac Toe Game 🎮

A simple and classic Tic Tac Toe game built for learning and fun.  
This project demonstrates basic programming concepts and game logic.

## Features
- Two-player mode
- Clear and easy-to-use interface
- Simple game logic implementation

## Installation
1. Clone the repository:
   git clone https://github.com/your-username/tic-tac-toe.git
2. Navigate to the project folder.
3. Run the game file (depending on your language setup).

## Usage
- Player 1 and Player 2 take turns.
- First to align three marks (X or O) wins.
- If all cells are filled without a winner, the game ends in a draw.
